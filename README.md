# Acentó — 西語重音練習

聽一個西班牙語單字，判斷重音符號（tilde）要標在哪個字母，或不用標。純靜態網頁，可直接部署到 GitHub Pages。

## 功能

- **練習**：用瀏覽器內建的 Web Speech API 朗讀單字（可重播、慢速），畫面只顯示去掉重音的拼法。點選字母或「不用標」作答後，馬上會顯示對錯、正確拼法、音節切分和適用的規則。
- **類別篩選**：Agudas、Llanas、Esdrújulas、Hiato、Verbos、Plurales。
- **一定混入「不用標」的字**：每一輪至少 30%。選到幾乎都要標的類別（例如 esdrújulas）時，會從其他類別補進不用標的字。
- **測驗**：大約 1/5 的字只保留給測驗，練習時不會出現。
- **統計**：分別記錄練習和測驗各類別的答對率，資料存在瀏覽器的 localStorage。
- **規則頁**：一般規則、母音相連，以及區別重音（tú/tu、él/el…）的參考表。

快捷鍵：`空白` 重播、`1`–`9` 依序選母音、`0` 不用標、`Enter` 下一題。

## 題庫

題庫在 `js/words.js`，每行一個字：用 `-` 分音節，重音音節全大寫，`|` 後面是選填的備註。

```
can-CIÓN
CA-sa
ha-BLÓ|pretérito, él（他說了）
```

規則說明是從音節和重音位置自動產生的，不用另外寫。新增字之後執行下面的指令，確認每個字的重音符號都和規則一致、也沒有重複：

```sh
node scripts/validate.js
```

哪些字保留給測驗，是用字的雜湊值決定的（`js/app.js` 的 `TEST_SHARE`）。

## 本機執行

直接用瀏覽器開 `index.html` 就能用。語音需要系統有安裝西班牙語語音。

## 部署

到 GitHub repo 的 Settings → Pages，Source 選 `main` 分支的根目錄即可。
